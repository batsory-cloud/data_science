# data_science

주식시장 투자자별 매매 데이터 및 관련 신호/패턴 분석 자료 모음.

## 원본 데이터

| 파일 | 설명 |
|---|---|
| `종합(KOSPI).xls`, `종합(KOSDAQ).xls` | KOSPI/KOSDAQ 종합지수 전체 거래일 OHLC 원본 데이터 |
| `코스피_순매수.csv`, `코스닥_순매수.csv` | KOSPI/KOSDAQ 투자자별(개인/외국인/기관계) 순매수 데이터 |
| `선물_순매수.csv`, `주식선물_순매수.csv`, `달러선물_순매수.csv` | 선물/주식선물/달러선물 투자자별 순매수 데이터 |
| `콜옵션_순매수.csv`, `풋옵션_순매수.csv` | 콜옵션/풋옵션 투자자별 순매수 데이터 |

## 3-/3+ 신호 분석

`3-3+_결과_0기준.xlsx`: 개인/외국인/기관계 시트별로 날짜마다 `3-`, `3+` 신호(○) 발생 여부를 기록한 원본 데이터.

이 원본을 기준으로 세 주체(개인, 외국인, 기관계)가 **동시에** 같은 상태(① 3-/3+ 모두 없음, ② 셋 다 3-/3+ 중 하나씩 있음)가 되는 날을 지속 기간별로 추출한 분석 파일:

| 파일 | 설명 |
|---|---|
| `3-3+_결과_0기준_단일일자_분석.xlsx` | 세 주체 동시 상태가 **딱 하루만** 고립되어 발생한 사례. 시트1: 동시 공백(신호 없음), 시트2: 동시 동그라미(신호 있음) |
| `3-3+_결과_0기준_연속2일이상_분석.xlsx` | 세 주체 동시 상태가 **2일 이상 연속**으로 발생한 사례(구간번호/연속일수/시작일/종료일 포함). 시트1: 동시 공백, 시트2: 동시 동그라미 |
